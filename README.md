# VetPet — base visual para reconstrução no Google AI Studio

Este pacote é uma base funcional inspirada no mockup da VetPet.

## Estrutura

- `index.html` — estrutura completa, seções, botões e links.
- `styles.css` — identidade visual, responsividade e animações.
- `script.js` — WhatsApp, Instagram, menu mobile, ano automático e animações.
- `assets/` — coloque aqui as imagens oficiais do Instagram/fachada/serviços.

## O que já funciona

- Menu com rolagem para cada seção.
- Menu mobile.
- Botões de WhatsApp.
- Botão de Instagram.
- Botão de localização no Google Maps.
- Rolagem suave.
- Animações leves de entrada.
- Layout responsivo para celular, tablet e desktop.

## IMPORTANTE

O número do WhatsApp ainda está como placeholder porque o número oficial não foi confirmado com segurança.
Abra `script.js` e substitua:

`55XXXXXXXXXXX`

pelo número oficial, somente números.

As imagens são placeholders. Para o resultado ficar fiel à VetPet real, substitua os arquivos dentro de `assets/` pelas fotos/logotipo oficiais fornecidos pelo cliente.

Também não foram colocados preços, horários ou promoções, porque esses dados precisam ser confirmados antes de entrarem no site.

## Prompt curto para o Google AI Studio

"Reconstrua este projeto como um site premium e responsivo da VetPet Clínica Veterinária & Pet Shop. Preserve a estrutura visual, hierarquia, textos confirmados, seções, espaçamentos, cores, tipografia, navegação, animações e funcionamento dos botões. Use as imagens oficiais fornecidas como assets. Não invente telefone, horários, preços, promoções, depoimentos ou informações comerciais. WhatsApp deve abrir conversa direta, Instagram deve apontar para o perfil oficial e Localização deve abrir o Google Maps. O resultado deve parecer um site real, editorial e contemporâneo, sem estética genérica de IA."
